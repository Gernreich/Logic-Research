Modus ponens in sixteen values

Classical modus ponens says that from P and P→Q you may conclude Q. Here P and Q are not just TRUE or FALSE. Each is one of the sixteen two-input functions, read row by row, the same way as in Gates of gates. This page works out what the rule becomes.

The result
from P and R = P→Q:  P∧R ≤ Q ≤ R

It is possible only when P∨R = TRUE. Here ≤ means “implies on every row”. Q is pinned on the rows where P is true and free on the rows where P is false. When P is TRUE, the two bounds meet and you get classical modus ponens: Q = R.

3 · One row at a time

Everything happens row by row

The sixteen-valued connectives work on each row separately, so modus ponens does too. On a single row, P and R = P→Q are ordinary booleans, and there are only four cases:

p = 1, r = 1
1
Q is pinned TRUE

This is classical modus ponens on this row.

p = 1, r = 0
0
Q is pinned FALSE

1→q is 0 only when q is 0.

p = 0, r = 1
01
Q is free

0→q is 1 whatever q is, so this row says nothing about Q.

p = 0, r = 0
✕
Impossible

0→q is always 1, so r can never be 0 here.

Stack four rows back together and you get the rule: the pinned rows make the lower bound P∧R. The free rows can be switched on up to R, which is TRUE on every free row. An impossible row anywhere rules out the whole pair.

6 · Counting

Why 81 pairs and 256 answers

Each row allows three (p, r) combinations out of four, so 3⁴ = 81 pairs are possible.

Those three combinations give 1, 1 and 2 choices for q, which is 4 per row. So the answers add up to 4⁴ = 256. That is every (P, Q) pair exactly once, because each (P, Q) produces exactly one R.

A P with k false rows leaves 2k answers. The more rows P covers, the more modus ponens tells you.

7 · The tautology form

(P ∧ (P→Q)) → Q still holds

Written as one formula, modus ponens is (P ∧ (P→Q)) → Q. Applied to sixteen-valued P and Q, gate of gates, it gives TRUE on all 256 pairs, because it is TRUE on every row separately. That formula is where the lower bound comes from: P ∧ (P→Q) is P∧Q, and it implies Q. The upper bound comes from the other tautology, Q → (P→Q): Q can never be truer than R.
