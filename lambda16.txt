The sixteen boolean functions of two variables as pure lambda terms
====================================================================

No shortcuts: every λ takes exactly one argument, every application
(f x) is bracketed, and nothing is abbreviated (no TRUE/FALSE/NOT names).

Church booleans:   true = λa.(λb.a)    false = λa.(λb.b)
Inside a body:     a = TRUE,  b = FALSE
                   ((q a) b) = q,  ((q b) a) = NOT q
Every body is ((p X) Y): X is the answer when p is true, Y when p is false.

idx = position in OPS (python/boolean16.py); entry i and 15 - i are complements.
TT TF FT FF = output for (p,q) = (T,T) (T,F) (F,T) (F,F).

Complement rule: swap every a and b in the body (after λb.) to get the
complement, idx 15 - i. Swapping the binders too only renames and changes nothing.


Beta reduction of all sixteen, on all four inputs
==================================================

TRUE = λx.(λy.x) and FALSE = λx.(λy.y) use x and y so they cannot clash with a and b.
Normal order: the leftmost, outermost redex is reduced first.
Each step says which variable was replaced and by what. "(thrown away)" means
the bound variable did not appear in the body, so the argument vanishes unreduced.
Every reduction ends at λa.(λb.a) = TRUE or λa.(λb.b) = FALSE.
